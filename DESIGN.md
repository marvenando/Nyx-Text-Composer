# Nyx Text Composer — Design Direction

- **Identity:** Editorial studio tool built to dock inside Adobe After Effects' dark workspace. Matte plum-obsidian surfaces anchored by Cannon Pink, warmed by Clam Shell labels, with Rajah as the primary action accent and Terracotta for secondary/destructive actions.
- **Dials:** `ENERGY 2` (confident editorial identity), `RHYTHM 2` (structured preset grid framed by distinct header, category rail, and collapsible workbench drawer), `MOTION 1` (calm static chrome; animation lives strictly inside preset previews on hover, focus, or explicit Auto-Play toggle).
- **Palette:**
  - Ground / Surfaces (deepened Cannon Pink): `#171215` (root), `#21191E` (chrome), `#2A2026` (card), `#1A1418` (preview stage)
  - Core Brand: `#854C62` (Cannon Pink)
  - Primary Text: `#F3F3F3` (Concrete)
  - Secondary Text: `#D9B6AA` (Clam Shell)
  - Primary Accent: `#FAA971` (Rajah, paired with `#171215` text)
  - Secondary / Destructive Accent: `#E67669` (Terracotta, paired with `#171215` text)
- **Typography:** System grotesque (`Segoe UI`, `-apple-system`, `BlinkMacSystemFont`, sans-serif) for crisp legibility at 11-13px panel sizes, with tabular numerals for duration and stagger values.
- **Radii:** Sharp hardware scale (`2px` badges, `3px` buttons/inputs/tabs, `4px` cards).
- **Wordmark:** Typographic `NYX` wordmark paired with `Text Composer` label (no decorative icon box).
